📋 Descripción del Proyecto

LSC Traductor es una aplicación que usa visión por computador para reconocer señas de la Lengua de Señas Colombiana (LSC) a través de la cámara web y traducirlas a texto en tiempo real.

🎯 Problema que Resuelve

Las personas sordas en Colombia enfrentan barreras de comunicación constantes con personas oyentes que no conocen la LSC. No existe actualmente una herramienta accesible y gratuita que traduzca LSC a texto en tiempo real. Este proyecto es un primer paso hacia cerrar esa brecha.

Tecnologías Utilizadas

Python 3.10+ MediaPipe Holistic scikit-learn OpenCV tkinter SQLite3

Características Principales

👐 Detección de Ambas Manos

Reconocimiento simultáneo de mano izquierda y derecha usando MediaPipe Holistic.

📍 Referencia Corporal Completa

Landmarks del torso (hombros, caderas) para contexto espacial completo.

⚖️ Normalización Inteligente

Posiciones relativas al centro del cuerpo, invariantes a distancia y tamaño.

💾 Historial de Traducciones

Base de datos SQLite para guardar y gestionar traducciones previas.

Pasos de Instalación

1

Clonar el Repositorio

git clone https://github.com/fray-leo/lsc-traductor.git
cd lsc-traductor
2

Crear Entorno Virtual (Recomendado)

python -m venv venv

# Linux / Mac
source venv/bin/activate

# Windows
venv\Scripts\activate
3

Instalar Dependencias

pip install -r requirements.txt

Esto instalará automáticamente:

  • mediapipe ≥ 0.10.9
  • opencv-python == 4.9.0.80
  • scikit-learn == 1.4.2
  • Pillow == 10.3.0
  • joblib == 1.4.0
  • numpy == 1.26.4
  • pyinstaller ≥ 6.0.0
4

Ejecutar la Aplicación

python main.py

Crear Ejecutable (.exe / .app)

Para distribuir la aplicación como un programa independiente:

# Ejecutable único (recomendado)
python build.py --onefile

# Carpeta con todos los archivos
python build.py

Funcionalidades de la Interfaz

➕ Grabar Nueva Seña

  1. Haz clic en "＋ Grabar Nueva Seña"
  2. Ingresa el nombre de la seña (ej: "hola", "gracias")
  3. Configura el número de muestras a capturar (mínimo 10)
  4. Presiona "▶ Iniciar Grabación"
  5. Después de la cuenta regresiva, mantén la seña visible frente a la cámara
  6. El sistema capturará automáticamente las muestras
  7. Las muestras se guardan en data/landmarks/{nombre}.csv

🔄 Ampliar Datos Existentes

Si intentas grabar una seña que ya existe, el sistema te preguntará si deseas agregar muestras adicionales. Esto mejora el reconocimiento sin sobrescribir los datos existentes.

🗑️ Limpiar Historial

El botón "Limpiar" en el panel derecho borra el historial de traducciones guardadas en la base de datos.

Gestión del Dataset (CLI)

# Listar todas las señas y su conteo
python -m App.logic.dataset_manager list

# Ver estadísticas detalladas
python -m App.logic.dataset_manager stats

# Eliminar todos los datos de una seña específica
python -m App.logic.dataset_manager clear gracias

🔨 Crear Tu Propio Ejecutable

Si prefieres compilar el ejecutable tú mismo desde el código fuente:

# Clonar el repositorio
git clone https://github.com/[usuario]/lsc-traductor.git
cd lsc-traductor

# Instalar dependencias
pip install -r requirements.txt

# Compilar para tu plataforma actual
python build.py --onefile

# El ejecutable se creará en la carpeta dist/

Scripts disponibles:

  • build_linux.sh - Para Linux (bash)
  • build_windows.bat - Para Windows (batch)
  • build.py - Script multiplataforma en Python

📝 Notas Importantes

  • Los ejecutables incluyen todas las dependencias necesarias
  • Debes descargar también las carpetas model/ y data/ con el modelo entrenado
  • El primer inicio puede ser más lento (el ejecutable se descomprime en memoria)
  • En macOS, puede requerir permisos de cámara adicionales
